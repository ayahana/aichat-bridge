# 群聊定制使用与验收

本分支基于 mmsx4717/aichat-bridge 0.1.6，保留原 MIT 许可和第三方声明。是实验性定制，不代表 QQ 或网页服务官方支持。

## 安全默认值与操作

1. 保留原官方 QQ 配置、群发现与专用网页绑定流程。旧数据无须重建；缺失策略自动解释为仅 @、上下文关闭、续聊关闭。
2. 设置页逐群开启扩展触发。昵称仅匹配本次正文开头且后有空白/标点（或全文恰为昵称），最多 10 个、各 32 字符，不匹配引用文本。引用触发只接受结构化 message_reference.message_id 且匹配最近五分钟本地确认发送成功的机器人消息 ID；字段未提供则不猜测。
3. 同人续聊默认关闭，可选 1–120 秒。只有一次明确触发的回复全部确认送达后才开启固定窗口；续聊、忽略、失败或取消的请求不会开启/延长窗口。窗口内仍受冷却和队列上限限制。
4. 默认冷却 10 秒（限制普通消息触发），扩展模式每群最多 3 个活动任务；@ 不受普通消息冷却限制，但仍受队列上限约束。暂停只停止接收新任务，既有任务继续；可在任务列表取消尚未领取的任务。
5. 普通群消息未触发时不创建提问、不回错误提示。未绑定群不持久化普通消息。已绑定群仅显示最近实际观察到普通事件的时间；未观察到不是证明没有权限。

## 上下文和隐私

默认不缓存无触发的聊天。显式勾选后，最多保留每群 8 条、每条 500 字符、按原消息时间两分钟内的已通过过滤的文字；每个助手的 QQ 存储最多 32 个群保有此缓存。普通事件去重辅助列表最多 2000 个 ID；实际任务沿用原有任务去重保护和保留期限。

先告知群成员并取得适用许可：触发时上述文字、当前问题和平台发言者标识会发送至所绑定的 AI 网站。必须使用仅供该群的独立对话，不要放私人历史、凭据或具备敏感操作权限的工具。提示中把历史标为资料只是降低混淆，不是安全隔离，不能阻止模型被群消息误导。不要据此授权 AI 执行群文本中的外部操作。

关闭上下文会清除缓存，并取消含上下文且尚未领取的任务；已领取/已发送网页内容无法撤回。重新绑定或解绑会清除本地会话、引用 ID 和上下文。缓存到期由后台维护清理；后台停止期间磁盘数据可能仍存在，但重新使用前必按原时间过滤。

## 诊断解释

- 排队：入队至领取；网页接手：原 bridge:started，不等于点击发送。
- 准备提交：唯一发送动作前的最佳努力信号。
- 已提交：网页当前用户消息与本次问题匹配后，不是单纯点击成功。
- 首次完整候选：通过既有归属与完成条件的候选，不是流式首 token。
- 原有生成/回群时间继续显示。缺失采样显示未知，后台收到采样的时间可能有传输延迟或乱序，不能当精确端到端测量。
- 阶段采样不阻塞结果、不重试、不改变任何回复时限，也不会自动重放问题。没有增加 Cookie、令牌或完整聊天诊断日志。

## 离线与人工验收边界

自动测试覆盖策略、设置、诊断以及上游队列/网页模拟回归。没有安装真实扩展、连接 QQ/AI 账号或进行真人群聊测试。依赖按锁文件从 npm 安装且禁用安装脚本。

人工验收清单：
- [ ] QQ 平台确实向本应用投递普通群事件，且其消息 ID 可在现有被动回复接口使用。网关 intent 未盲目更改；权限未确认就保持仅 @。
- [ ] 默认模式仍仅 @，未开启群和普通闲聊不会回答。
- [ ] 昵称、确切引用及成功回复后的同人续聊行为符合预期；不同成员和过期窗口不触发。
- [ ] 群成员同意上下文范围，专用网页无私人资料；停用后无未领取旧上下文再提交。
- [ ] 重复事件、机器人自身消息、突发消息与重连不会重复提问或互相循环。
- [ ] Edge/Chrome 后台、睡眠、网页验证、人工草稿、图片和网页变更场景逐项验证；现有超时与归属保护仍生效。
- [ ] 飞书及四个网页助手按原流程回归，五条 QQ 回传预算与不明确发送结果不盲目重试仍保留。

防循环仅能识别 QQ 标记为机器人、READY 提供的本机器人身份和本地确认的已发消息 ID；无法保证识别平台未标记的其它机器人。请不要让多个机器人互相配置对方昵称，保留冷却与队列上限。引用字段未被实际事件提供时，该触发会保持关闭效果，不会从引用正文猜测作者。
